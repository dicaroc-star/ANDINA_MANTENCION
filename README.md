
# ANDINAMANTENCIÓN
## Sistema de Gestión de Mantenimiento Industrial

**Proyecto académico:** Ingeniería de Requisitos  
**Institución:** Duoc UC  
**Caso de estudio:** Manufacturas Andina S.A.  
**Repositorio:** ANDINA_MANTENCION

---

## 1. Descripción del proyecto

AndinaMantención es una aplicación web orientada a mejorar la administración del mantenimiento industrial en Manufacturas Andina S.A., empresa dedicada a la fabricación de envases plásticos.

El proyecto busca centralizar la información de máquinas, fallas, órdenes de trabajo, mantenimiento preventivo, repuestos y costos operacionales.

## 2. Problemática identificada

La empresa presenta dificultades como:

- Información dispersa en planillas Excel y documentos físicos.
- Falta de trazabilidad del mantenimiento.
- Ausencia de identificadores únicos para las máquinas.
- Predominio del mantenimiento correctivo.
- Dificultades para controlar repuestos y costos.
- Falta de indicadores para apoyar decisiones.

## 3. Objetivo general

Desarrollar una aplicación web que permita gestionar y controlar los procesos de mantenimiento industrial, mejorando la trazabilidad, disponibilidad de información y eficiencia operativa.

## 4. Funcionalidades contempladas

- Administración de usuarios y roles.
- Registro y gestión de equipos industriales.
- Identificación de máquinas mediante códigos QR.
- Registro y seguimiento de fallas.
- Creación y administración de órdenes de trabajo.
- Asignación de técnicos responsables.
- Programación de mantenimiento preventivo.
- Control de inventario de repuestos.
- Historial de intervenciones.
- Generación de reportes e indicadores.

**Nota:** Las funcionalidades anteriores corresponden al alcance previsto del proyecto. Su implementación se verificará mediante las pruebas y evidencias de cada sprint.

## 5. Tecnologías utilizadas en el repositorio

- Python: componentes del servidor.
- JavaScript: lógica de la interfaz.
- HTML: estructura de las páginas web.
- CSS: diseño visual.
- Git y GitHub: control de versiones.
- Docker y Render: archivos de configuración para despliegue.

La implementación de la base de datos será documentada y validada durante el desarrollo.

## 6. Organización del proyecto

El repositorio contiene archivos como:

- `index.html`: interfaz web.
- `styles.css`: estilos visuales.
- `app.js`: lógica del cliente.
- `server.py`: componente del servidor.
- `schema.py`: módulo asociado al esquema de datos.
- `security.py`: módulo relacionado con seguridad.
- `requirements.txt`: dependencias de Python.
- `Dockerfile`: configuración del contenedor.
- `render.yaml`: configuración de despliegue.
- `test_app.py`: archivo de pruebas.
