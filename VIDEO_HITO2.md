# Grabación orientativa — Hito 2

Este material NO pretende sustituir la grabación de funcionamiento en Oracle/Render que solicita la asignatura.

Se genera con **la aplicación real de AndinaMantención**, en servidor local Python y **adaptador SQLite efímero de pruebas**, usando datos ficticios.

Permite mostrar: acceso, panel principal, activos, QR, incidencias, órdenes, mantenimiento preventivo y repuestos.

**El resultado no confirma que la aplicación desplegada en Render se comporte igual ni que las transacciones funcionen en Oracle real.** Para la entrega definitiva, conviene hacer una grabación equivalente en https://andina-mantencion.onrender.com/ con la cuenta del estudiante, ocultando correos y credenciales. El video se produce automáticamente en GitHub Actions y queda disponible como artefacto durante 30 días.
